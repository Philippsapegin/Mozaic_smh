# Мозаика

Простой редактор фото и документов для журналистов. Работает на Windows; изображения обрабатываются на вашем компьютере.

## Скачать и запустить

**[Скачать Мозаику для Windows](https://github.com/Philippsapegin/Mozaic_smh/releases/latest/download/Mozaic-Windows.zip)**

Распакуйте архив и откройте ярлык **«Мозаика»**. Для установки запустите **«Установить Мозаику.exe»** — оба файла находятся сразу в корне архива.

## Три инструмента

- **Мозаика** — автоматически находит лица и закрывает их по контуру. Ненужные маски можно отключить. ЛКМ рисует мозаикой, ПКМ стирает, колесо меняет размер кисти.
- **Маркер** — выделяет фрагменты документов: ЛКМ рисует толстую прямую линию, ПКМ — прямоугольник. Колесо над линией меняет её толщину. Пересечения сохраняют одинаковый цвет.
- **Баббл** — добавляет читаемый текст в белой плашке с мягкой тенью и выноской. Плашка и кончик хвостика перетаскиваются отдельно; доступны размер текста и жирное начертание.

Снизу — обрезка, поворот и сохранение PNG. `Ctrl+Z` отменяет последнее действие. Настройки инструментов сохраняются при смене изображения.

При выходе новой версии приложение предложит обновиться. Интернет нужен только для скачивания и обновлений; фото никуда не отправляются.
