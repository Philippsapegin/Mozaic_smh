# Мозаика

Приложение для подготовки журналистских изображений на Tauri 2. Обработка фото, поиск лиц и построение контуров выполняются на компьютере пользователя. Сервер, Python, ComfyUI и подключение к интернету для работы не нужны.

## Windows-приложение

Готовые файлы лежат в `release/`:

- `Mozaic.exe` — запуск без установки; нужен установленный Microsoft Edge WebView2 Runtime.
- `Mozaic-1.0.0-setup.exe` — установка для текущего пользователя. Установщик содержит WebView2 Runtime для установки без интернета, если его нет на компьютере.

Все модели, шрифты и вычислительные библиотеки включены в приложение. Фото не отправляются за пределы компьютера. Файлы открываются и сохраняются через системные диалоги Windows; перетаскивание из Проводника также поддерживается.

## Работа

- **Мозаика:** лица находятся двумя детекторами — MediaPipe и YOLO. Маска следует внешнему контуру лица; если контур не найден, используется округлая маска. Переключатель у лица включает и отключает мозаику. ЛКМ добавляет её кистью, ПКМ стирает. Колесо меняет размер кисти.
- **Маркер:** ЛКМ растягивает прямоугольник, ПКМ удаляет последний. Все прямоугольники образуют одну маску `#ff4400`, `hard-light`, 27%, без усиления на пересечениях.
- **Баббл:** клик ставит кончик выноски. Тело и кончик перетаскиваются отдельно. Текст переносится только клавишей Enter. Кнопка `B` включает жирное начертание для всего баббла.
- **Консоль:** загрузка, обрезка, поворот на 90° и сохранение PNG. Кнопка `×` рядом с обрезкой сбрасывает рамку.

`1`, `2`, `3` переключают инструменты. `Ctrl+Z` отменяет действие, включая при русской раскладке. Фото автоматически вписывается в рабочую область; колесо не меняет масштаб.

## Разработка и сборка

Нужны Node.js, Rust с целью `x86_64-pc-windows-msvc`, Microsoft C++ Build Tools с Windows SDK и WebView2 Runtime. Интернет нужен для первоначальной загрузки зависимостей сборки.

```powershell
npm ci
npm run desktop:dev
```

Windows-сборка:

```powershell
npm run desktop:build
```

Tauri создаёт приложение в `src-tauri/target/release/mozaic.exe`, установщик — в `src-tauri/target/release/bundle/nsis/`. Для разработки интерфейса в браузере достаточно `npm run dev`; это также использует локальные модели и не обращается к серверу распознавания.

Модели находятся в `public/models/`. WASM ONNX Runtime копируется из установленного npm-пакета перед запуском и сборкой. YOLO выполняется в отдельном Worker, чтобы не блокировать интерфейс. `scripts/export-face-model.py` нужен только для повторной конвертации исходных весов YOLO в ONNX; Python в сборку не включается.

## Проверка

```powershell
npm test
node tests/face-contour.mjs "C:\path\to\portrait.jpg"
node tests/desktop.mjs "C:\path\to\portrait.jpg"
```

Проверки используют установленный Microsoft Edge. Проверка контуров и EXE рассчитана на контрольный портрет MediaPipe размером 820 × 1024. Проверка EXE требует готовую release-сборку и проверяет системные диалоги, локальные модели и PNG в пути с кириллицей. В настольной версии YOLO использует один поток WASM внутри отдельного Worker: это обходит зависание вложенных Worker в WebView2 при загрузке из протокола Tauri. Исходная HTML-версия сохранена в `legacy/`; предыдущий Python-сервис сохранён в `face_check/` и в приложении не используется.

Модели и библиотеки: [Tauri](https://v2.tauri.app/), [MediaPipe Face Detector](https://ai.google.dev/edge/mediapipe/solutions/vision/face_detector), [MediaPipe Face Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker), [Ultralytics](https://docs.ultralytics.com/), [ONNX Runtime](https://onnxruntime.ai/), [Roboto Condensed](https://github.com/google/fonts/tree/main/ofl/robotocondensed).
